# SMART RECRUITMENT — Frontend
React 18 + Vite + Tailwind CSS v4.

```bash
npm install
npm run dev
```

The landing page routes to Espace Recruteur and Portail Candidat. New portal accounts, profile fields, demo offers and applications use browser `localStorage` only; see the root README for integration and security limitations. The legacy recruiter workflow continues to use the FastAPI API for offer creation, PDF CV upload and analysis.
